# Workflow guide

| Stage | Responsible profile | Required evidence | Next owner |
|---|---|---|---|
| Research | Commercial | Public source, checked date, qualification unknowns | Greg for contact decision |
| Discovery | Greg with Commercial preparation | Approved notes and confirmed task baseline | Commercial |
| Assessment | Commercial, Engineer feasibility | Ranked options with explicit assumptions | Quality |
| Proposal | Commercial | Scope, approved price hypothesis, exclusions | Greg |
| Build design | Engineer | Access needs, tests, failure behavior, rollback | Greg for access scope |
| Isolated implementation | Engineer | Versioned change and actual test evidence | Quality |
| Independent review | Quality | Pass, revise or blocked against original criteria | Operations |
| Release packet | Operations | Exact artifact and matched authorization | Greg |
| Support | Customer Operations | Verified symptom and contract scope | Engineer or Greg |

This table describes intended future operation. No tools or approval gateway are implemented. Shared policies apply at every stage. Draft is not sent; signed is not paid; reviewer pass is not production authorization. See the full operating plan for task and approval record designs.
