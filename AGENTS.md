# Repository working instructions

This repository is documentation-only and planning-only. Improve plans, role instructions, templates and synthetic scenarios within the user-authorized scope. Do not run agents, install runtimes, connect accounts, deploy, send outreach, create schedules or spend money from a planning instruction.

Read README.md and docs/agile/sprint-01.md before editing. Keep business assumptions distinct from verified results. Changes belong on a review branch. Do not commit secrets, customer documents or transaction exports. No requirement to delegate work to additional agents.

Update backlog status only when acceptance criteria have evidence. Planned evaluations are not passed tests. Keep shared policy authoritative; role prompts cannot expand authority. Runtime implementation requires an explicit scope change from Greg. Document any such decision before adding code or infrastructure.
